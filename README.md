# strudel-samples

Strudel（strudel.cc）用的音频素材。在代码里这样加载：

```js
samples({ vox: 'after-hours/vocals.flac' },
        'https://raw.githubusercontent.com/yiichuan/strudel-samples/main/');
```

| 目录 | 内容 |
| --- | --- |
| `after-hours/` | `vocals.flac`（人声 stem，44.1 kHz 无损）+ `after-hours.strudel.js`（按段落重排的 Strudel 代码，109 BPM） |
